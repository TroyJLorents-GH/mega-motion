# Brand motion system (deliverable the client keeps)

Studios are hired to define how a brand moves, not only to animate one page.

```
SIGNATURE MOVE: the one motion the brand is recognised by (describe; reference clip)
EASES (three, named): enter ____  move ____  exit ____   (one optional pop, hero only)
SPRING: damping ___ (one for the whole product)
DURATION SCALE: feedback ___ ms / move ___ ms / reveal ___ ms / exits ___% of entrance
STAGGER: words ___ ms, items ___ ms, overlap ___%
DIRECTION: the brand's current (which way things travel) and carriers that persist
TYPE IN MOTION: reveal method, letters allowed for ___ only
SOUND: on/off by default; cue palette
NEVER: what this brand never does (e.g. bounce on text, particle backgrounds, spinning logos)
REDUCED MOTION: what replaces the signature move
KIT: links to the reference implementations of each item
```

# Motion spec for handoff to another team's developers

One row per animated element, plus a reference clip for each beat.

| Element (selector or name) | Trigger (load, scroll range, hover, click) | Property | From | To | Duration or scroll distance | Delay | Easing (named token) | Reduced-motion version | Notes |
|---|---|---|---|---|---|---|---|---|---|

Also hand over: the tokens file, the beat table, the QA thresholds the build must pass, and a reference clip per beat (MP4 with frame numbers burned in).

**Estimating:** give each beat a rough effort (hours) so a client can cut beats to fit a budget; the most expensive are usually custom shaders, live 3D with variants, and anything with sound sync.
